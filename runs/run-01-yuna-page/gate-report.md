# run-01 게이트 판정 — yuna.page 공개 화면

> 대상 산출물: `index.html` (소개 + 요청 폼 + 접수 완료)
> 범위: **공개 화면까지** (관리자 요청함·상세는 run-02로 분리 — 지식재산/범위 분리)
> 판정 방법: 전부 숫자/파일 존재로 측정. 기준 미달이면 해당 페이즈로 되돌림.
> 실행: 2026-10-09 (자동 진행), 사람 리뷰 예정 2026-10-10

## P1 — 소재·요구 정리 · 게이트 G1
| 항목 | 기준 | 실측 | 판정 |
|---|---|---|---|
| 유저스토리 수 | =5 | 5 (US-1~5) | ✅ |
| ★(어기면 안 되는 것) | ≥2 | 2 (★1,★2) | ✅ |
| 아동 민감정보 입력 필드(학교·학급·생일·주소) | =0 | 0 | ✅ ★2 |

## P2 — 화면 흐름 설계 · 게이트 G2
| 항목 | 기준 | 실측 | 판정 |
|---|---|---|---|
| 핵심 화면 정의 수 | ≥2 | 2 (소개+폼 / 접수 완료) | ✅ |
| 첫 화면 주 행동(주 버튼) | =1 | 1 ("연아 아빠에게 보내기") | ✅ |
| 공개 화면의 관리자 링크 | =0 | 0 | ✅ |

## P3 — 디자인 적용 · 게이트 G3
| 항목 | 기준 | 실측 | 판정 |
|---|---|---|---|
| 색 토큰 사용 수 | ≥7 | 9 (bg·surface·ink·ink-muted·primary·primary-ink·line·danger·ok) | ✅ |
| 타이포 스케일 수 | ≥6 | 7 (40·20·16·15·14·13·12) | ✅ |
| 터치 타깃 최소 높이 위반(버튼/인풋/옵션) | 0 | 0 (버튼52·인풋48·옵션44) | ✅ |
| 입력 라벨 누락 | 0 | 0 (text/date/checkbox 6개 + 라디오 그룹 legend 3개 모두 연결) | ✅ |
| `alt`/대체텍스트 없는 의미 이미지 | 0 | 0 (아바타 SVG는 role=img+aria-label, 그 외 `<img>` 없음) | ✅ |

> 참고: 동의 체크박스 자체는 22px지만 연결된 라벨(for=agree)이 커서 실질 탭 영역은 충분. run-02에서 래퍼 전체를 탭 영역으로 승격 검토.
