## 적용한 게이트 (→ `harness/rules.yaml`)

- **★ 아동 개인정보 비식별** — 공개용 와이어에서 이름(연아/YUNA)을 전부 일반 표현(아이·보호자·사진 모음…)으로 교체, 실제 사진·소개·장래희망은 **placeholder**.
- **★ 비공개 전달 안내** — 문의 폼에 "남긴 메시지·연락처는 보호자에게만 전달, 공개 안 됨" ⓘ 안내. 동의 체크박스 대신 안내 문구.
- **민감정보 필드 금지** — 학교·학급·생일·주소 없음. 필드는 **이름·메시지·연락처 3개**로 덜어냄.
- **디자인 규칙** — 색/타입 토큰화, 주 버튼·입력 44px+, BGM **자동재생 금지**(작은 아이콘 토글), 이미지 자리 대체(placeholder).

## 페이즈 흐름 (손작업 → 산출물)

1. **스펙** — story-service(유저스토리)·story-work(손작업 흐름)·design.md 기준으로 공개 화면 정의.
2. **디자인** — 컬러 시안 → 흑백 와이어프레임으로 구조화. 화면 → **상태 변형**(폼 4종) → **컴포넌트 변형**까지.
3. **검증/덜어내기** — 비식별·비공개·필드 최소화 게이트 적용, 높이·너비 통일로 정리.
