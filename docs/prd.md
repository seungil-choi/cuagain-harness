## 한 줄
연아가 다시 만나고 싶은 친구에게 QR 명함을 건네면, **친구의 부모님이 QR로 접속해 연아 아빠에게 메시지와 만남 요청을 보낼 수 있는** 모바일 웹.

## 사용자
| 사용자 | 원하는 결과 |
|---|---|
| 친구 부모님(주 이용자) | 가입 없이 간단히 요청하고, 익숙한 수단으로 답장받기 |
| 연아 아빠(관리자) | 요청 확인 → 연락 → 처리 상태 관리 |

## 핵심 행동
"연아 아빠에게 메시지 남기기" 하나. 소개(사진·그림·손글씨)는 누구 페이지인지 알아보고 친근함을 느끼게 하는 역할.

## 공개 화면(이 하네스 범위)
- 소개(히어로·About·Dream·갤러리) + 메시지 폼(친구 이름·전할 메시지·연락처) + 접수 완료
- 가입·앱 설치 없음. 모바일 우선(360px), 터치 44px+, 색만으로 상태 전달 금지.

## 관리자/운영 (run-02 이후)
요청함·상세·상태 관리·알림(문자+메일, 재시도)·90일 자동 삭제.

## 꼭 지킬 것 (★ = 게이트)
- **★1** 제출 메시지·연락처는 관리자에게만. 공개 화면·공개 API에 타인 노출 금지.
- **★2** 아동 민감정보(학교·학급·생일·주소) 수집·노출 금지. 사진 EXIF 제거·noindex.

## 지식재산
"수락 후 연결·안심번호 중계"는 출원 전 외부 공개 금지(공지예외 2027-10-05) → 하네스/산출물 범위 밖.
