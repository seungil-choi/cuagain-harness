# design.md — 디자인 판단 맥락 (yuna.page)

> 색·타이포·간격·컴포넌트·접근성 규칙. AI가 화면을 만들 때 이 문서를 근거로 판단한다.
> **근거: 실제 yuna.page(`yeona-contact/public/style.css`·`card.html`)에서 추출** + PRD §9 품질 기준.

## 0. 톤 & 원칙
- **따뜻하고 안심되는 + 아이다운 유쾌함.** 처음 보는 친구 부모님이 "연아 아빠가 확인하는 곳"이라는 신뢰를 먼저 느끼되, 손글씨·크레용 낙서로 "우리 아이 페이지" 감성을 준다.
- **시그니처 그라데이션(분홍→하늘)은 얇은 선·작은 포인트에만.** 면으로 쓰지 않는다(이름 밑줄, Dream 바, 포커스 테두리 등).
- **행동은 하나.** 첫 화면의 핵심 행동은 "연아에게 메시지 보내기".
- **움직임은 조심스럽게.** 손글씨 그리기·낙서는 **사용자 시작/스크롤 기반**, `prefers-reduced-motion` 존중. **배경음악은 자동재생 금지 — 우상단 토글 버튼으로만.**

## 1. 색 (토큰)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#f7f4f1` | 배경(따뜻한 페이퍼) |
| `--white` | `#ffffff` | 카드·입력 |
| `--ink` | `#1d1b20` | 본문·버튼 바탕 |
| `--ink-2` | `#4a4650` | 본문 보조(≈8:1) |
| `--ink-3` | `#6f6a74` | 라벨·힌트(≈5:1) |
| `--line` | `#e4dde6` | 연보라빛 회색 선 |
| `--tint` | `#fbf3f7` | 아주 옅은 분홍 면 |
| `--blush` / `--mist` | `#e9b8c6` / `#b5d3e6` | 연아 분홍·하늘 (포인트) |
| `--grad` | `#e2a3b8 → #9cc6e2` | 시그니처 그라데이션(선·포인트) |
| `--error` / `--focus` | `#b3261e` / `#4d84b8` | 오류 / 포커스 |

- 상태는 **색만으로 전달 금지.** 오류=빨강 테두리+문구, 선택/완료=아이콘+문구. 버튼 글자 대비 ≥ 4.5:1(ink 바탕에 분홍 글자 `#f4c6d4` ≈10:1).

## 2. 타이포
- 본문: `"Pretendard Variable", Pretendard, -apple-system, "Noto Sans KR", sans-serif` · 16px · lh 1.6 · letter-spacing -.01em · `word-break: keep-all`
- 손글씨 포인트(이름/키비주얼): 실제는 `handwriting.svg`(획 애니메이션). 대체 폰트 `Nanum Pen Script`.
- 스케일: `name 44(+그라데이션 밑줄) · name-en 22 · dream clamp(18~22) · body 17 · sheet-title 20 · label 13(uppercase .12em) · hint/caption 13~14`

## 3. 간격·모양
- radius: `--radius 14` (입력 12 · 시트 24 24 0 0)
- 입력 min-height **52px**, 버튼 min-height **56px**, 아이콘 버튼 **44px**
- 갤러리: 3열 그리드, gap 2px, 타일 aspect 1
- 페이지 폭 `max-width 520px`, safe-area inset 반영

## 4. 컴포넌트
- **히어로**(3:4): 사진 + 크레용 낙서(SVG) + 손글씨 "My Name is YUNA"(탭하면 재생, 스크롤 시 서서히 흐려짐). 사진 뜨기 전 `blush→mist` 배경.
- **블록+라벨**: `About / Dream / Gallery` 등 대문자 라벨.
- **이름**: `연아 (YUNA)` + 그라데이션 밑줄. **Dream**: 그라데이션 좌측 바 + 한 줄.
- **갤러리**: 9장 노출 + **"사진 N장 더보기"**(aria-expanded) + 라이트박스(크게 보기·좌우 이동).
- **토글 BGM**: 우상단 고정 원형 버튼(aria-pressed), **자동재생 아님**.
- **하단 CTA**(고정): "연아에게 메시지 보내기" (ink 바탕·분홍 글자).
- **메시지 바텀시트**: 아래에서 올라오는 `dialog`, 그립으로 끌어 닫기, ⓘ 안내 팝(전달/보는사람/답장).
- **라이트박스**: 전체화면 사진 뷰.

## 5. 폼 원칙 — "덜어내기" (피로도↓, 2분 완료)
- **필수 3개만: 친구 이름 · 전할 메시지 · 답변받을 연락처(휴대폰).**
- 목적·희망일정·회신수단 라디오·연락 편한 시간 → **넣지 않는다.**
- **동의 체크박스 없음.** 대신 ⓘ 안내로 전달 방법·보는 사람·답장을 알린다(수집 최소·목적 명확·90일 삭제).
- 입력: 명시적 `label`, `tel`/적절한 inputmode, 포커스 그라데이션 테두리, 글자수 카운터, 오류는 필드 아래+첫 오류로 포커스.

## 6. 접근성·반응형 (= 게이트로 측정)
- 360px 가로 스크롤 0 · 터치 타깃 44px+ · 모든 입력 라벨 연결 · 보이는 포커스 · 색만으로 상태 금지 · 이미지 실패해도 폼 작동 · `prefers-reduced-motion` 존중.

## 7. 금지 (서비스 게이트 연동)
- 공개 화면에 **타인의 요청/연락처** 노출 금지(★1).
- 아동 민감정보(학교·학급·생일·주소) 입력·노출 금지, 사진 EXIF 제거(★2).
- 공개 첫 화면에 관리자 기능 링크 노출 금지 · 검색 노출 차단(noindex).
