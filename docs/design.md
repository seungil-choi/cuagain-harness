# design.md — 디자인 판단 맥락 (yuna.page)

> 색·타이포·간격·컴포넌트·접근성 규칙. AI가 화면을 만들 때 이 문서를 근거로 판단한다.
> 근거: PRD §9 품질 수용 기준 + 서비스 톤("우리 아이 페이지" 감성, 손글씨 키비주얼).

## 0. 톤 & 원칙
- **따뜻하고 안심되는.** 친구 부모님이 처음 보는 낯선 페이지지만 "연아 아빠가 확인하는 곳"이라는 신뢰가 먼저 와야 한다.
- **아이답지만 유치하지 않게.** 손글씨 포인트 1곳(이름)만, 나머지는 단정하게.
- **행동은 하나.** 첫 화면의 핵심 행동은 "연아 아빠에게 보내기". 나머지는 보조.

## 1. 색 (토큰 7)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FFFDF7` | 배경(따뜻한 크림) |
| `--surface` | `#FFFFFF` | 카드·입력 배경 |
| `--ink` | `#2E2A24` | 본문 텍스트 |
| `--ink-muted` | `#7C756B` | 보조 텍스트·플레이스홀더 |
| `--primary` | `#F28C4B` | 주 버튼·강조(따뜻한 주황) |
| `--primary-ink` | `#FFFFFF` | 주 버튼 위 글자 |
| `--line` | `#ECE4D8` | 경계선·구분선 |
| (상태) `--danger` | `#D64545` | 오류 텍스트·오류 테두리 |
| (상태) `--ok` | `#3F9D6D` | 성공·접수 완료 |

- 상태는 **색만으로 전달하지 않는다.** 오류=빨강 테두리 **+ 아이콘/문구**, 성공=초록 **+ ✓/문구**.
- 명도 대비: 본문/배경 ≥ 4.5:1, 큰 글자/버튼 ≥ 3:1 목표.

## 2. 타이포 (스케일 6)
- 한글 본문: `Pretendard, -apple-system, "Noto Sans KR", sans-serif`
- 손글씨 포인트(이름만): `"Nanum Pen Script", cursive` — 폰트 실패 시 본문 폰트로 폴백.
- 스케일: `display 28 / title 22 / body 16 / label 14 / caption 13 / button 16`
- 본문 line-height 1.6, 버튼/라벨 1.3. 최소 본문 16px(모바일 확대/자동 줌 방지).

## 3. 간격 (4px 베이스)
`4 · 8 · 12 · 16 · 24 · 32 · 48`. 섹션 간 24, 카드 안쪽 16, 입력 사이 16, 라벨↔필드 8.

## 4. 모양
- radius: `button 12 / input 12 / card 16`
- 그림자: 카드 `0 1px 3px rgba(0,0,0,.06)`. 장식용 그림자 남발 금지.
- 테두리: 입력 1px `--line`, 포커스 2px `--primary`.

## 5. 컴포넌트 규칙
- **버튼**: 최소 높이 **48px**, 좌우 패딩 20, 주 버튼 1개만 강조. 전체폭 권장(모바일).
- **입력/폼 필드**: `label`(명시적, for-id 연결) → `input` → 오류 문구(필드 아래). 적절한 `inputmode/type`(전화=tel, 이메일=email). 터치 타깃 ≥ 44px.
- **라디오(회신 수단)**: 각 선택지 터치 영역 44px+, 선택 상태는 색+테두리+체크표시.
- **카드**: 소개/폼/완료를 카드로 구분. 360px에서 좌우 여백 16.
- **이미지(소개 사진/그림)**: `alt` 필수, 로딩/실패 시 대체 블록(이니셜·그림 플레이스홀더)으로도 화면 성립. 자동재생·장식 애니메이션 금지.

## 6. 접근성·반응형 (= 게이트로 측정됨)
- 360px 폭에서 **가로 스크롤 0**.
- 모든 입력에 `label` 연결(개수 = 필드 개수).
- 눈에 보이는 포커스 링, 키보드만으로 전체 폼 사용 가능.
- 색만으로 상태 전달하는 곳 0.
- 이미지가 깨져도 폼 제출 가능.

## 7. 금지 (서비스 게이트 연동)
- 공개 화면에 **다른 방문자의 요청/연락처**를 절대 표시하지 않는다(★1).
- 아동 민감정보 입력 필드(학교·학급·생일·주소)를 **두지 않는다**(★2).
- 관리자 기능 링크를 공개 첫 화면의 주요 행동으로 노출하지 않는다.
